# 🌿 หมอพืช AI (AI Plant Doctor)

เว็บแอปมือถือ (PWA) สำหรับร้านวัสดุการเกษตร/เกษตรกร

- 📸 **ถ่ายรูปพืช** → AI วินิจฉัยโรค/แมลง/ขาดธาตุ พร้อมความมั่นใจและความรุนแรง
- 🧪 **แนะนำสารออกฤทธิ์ (ชื่อสามัญ)** อัตราใช้ ช่วงพ่น PHI กลุ่มกลไก FRAC/IRAC และวิธีจัดการในแปลง
- 🧴 **สแกนฉลากยา** → อ่านชื่อการค้า ชื่อสามัญ ความเข้มข้น เลขทะเบียน และเทียบว่าเหมาะกับโรคที่วินิจฉัยหรือไม่
- 🧾 **ออกบิล** ใบส่งของ / บิลเงินสด / ใบกำกับภาษี+ใบเสร็จรับเงิน / ใบกำกับภาษีอย่างย่อ (VAT รายรายการ, ยอดเป็นตัวอักษรไทย, พิมพ์ A4/บันทึก PDF)
- 🕘 **ประวัติ** ทุกอย่างเก็บในเครื่อง (localStorage)

## เริ่มใช้งาน

ต้องมี [Node.js](https://nodejs.org) 18 ขึ้นไป (ไม่ต้อง `npm install` เพราะไม่มี dependency)

```powershell
cd "C:\Users\User Lenovo\Desktop\ai plant"
npm start
```

เปิด <http://localhost:3000> (ถ้าพอร์ตชนกัน ตั้ง `PORT` ในไฟล์ `.env`)

### เปิดใช้ AI จริง

1. ขอ API key ที่ <https://console.anthropic.com>
2. คัดลอก `.env.example` เป็น `.env` แล้วใส่ `ANTHROPIC_API_KEY=...`
3. รีสตาร์ท `npm start` — แถบมุมขวาบนจะเปลี่ยนจาก "โหมดสาธิต" เป็น "AI พร้อมใช้"

ถ้ายังไม่ใส่ key แอปจะทำงานใน **โหมดสาธิต** (ผลลัพธ์ตัวอย่าง ไม่ได้มาจากรูปจริง) เพื่อให้ลองใช้งานและออกบิลได้ทุกฟังก์ชัน

### ใช้บนมือถือ

- โทรศัพท์และคอมต้องอยู่ Wi‑Fi เดียวกัน เปิด `http://<IP ของคอม>:3000`
- ปุ่ม "ถ่ายรูป" จะเปิดกล้องของเครื่องโดยตรง
- อยากติดตั้งเป็นแอปบนหน้าจอ (PWA) ต้องเปิดผ่าน HTTPS (เช่น deploy ขึ้น Render/Railway/VPS แล้วตั้ง `ANTHROPIC_API_KEY` เป็น environment variable)

  store.js thai.js camera.js api.js ui.js icons.js

## ข้อควรระวัง

- **ผลวินิจฉัยของ AI เป็นข้อมูลประกอบการตัดสินใจ** ไม่ใช่คำสั่งใช้ยา ให้อ่านฉลาก ใช้เฉพาะผลิตภัณฑ์ที่ขึ้นทะเบียนกับพืชนั้น และปรึกษาเจ้าหน้าที่เกษตรเมื่อโรคลุกลาม
- ชื่อการค้าที่ AI แนะนำเป็นเพียงตัวอย่าง ตรวจเลขทะเบียน วอส. ก่อนจำหน่าย/ใช้เสมอ
- **ภาษี**: สินค้าเกษตรบางประเภท (เช่น ปุ๋ย/ยาป้องกันกำจัดศัตรูพืชที่ใช้ในการเกษตร) อาจได้รับยกเว้น VAT — แอปให้เลือกโหมดภาษีรายรายการ โปรดตรวจสอบกับนักบัญชี/สรรพากร ก่อนใช้ออกเอกสารจริง
- ใบกำกับภาษีเต็มรูปต้องมีข้อมูลผู้ขาย/ผู้ซื้อครบ แอปจะเตือนรายการที่ยังขาด แต่ไม่ได้แทนการตรวจสอบของผู้ประกอบการ
- ข้อมูลร้าน ลูกค้า และบิลเก็บในเบราว์เซอร์เครื่องนี้เท่านั้น (ล้างข้อมูลเบราว์เซอร์ = ข้อมูลหาย) ควรสำรองเอกสารที่ออกเป็น PDF
